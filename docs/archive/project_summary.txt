# Project Summary: Quantum-Safe Banking Transaction PoC

This document provides a final overview of the Proof-of-Concept (PoC) developed to demonstrate the transition from classical to post-quantum cryptography in banking systems.

## 🎯 Project Goals
The primary objective was to evaluate the performance impact of **ML-KEM-768** (FIPS 203) compared to **RSA-2048** and to simulate the real-world threat of **"Harvest Now, Decrypt Later"** attacks.

## 🚀 Key Features

### 1. Dual Cryptographic Engine
- **Classical**: RSA-2048 (OAEP/PSS) for encryption and signing.
- **Post-Quantum**: ML-KEM-768 for key encapsulation, combined with AES-256-GCM for symmetric encryption.
- Side-by-side execution for every transaction to provide direct performance comparisons.

### 2. Interactive Dashboard
- Real-time visualization of encryption, decryption, and key generation times using **Chart.js**.
- Automated load generator to simulate high-traffic scenarios and collect statistically significant metrics.
- Key size comparison charts highlighting the larger overhead of PQC.

### 3. Harvest Now, Decrypt Later (HNDL) Simulation
- **Phase 1 (Harvest)**: Encrypting and "stealing" classical RSA-15 data.
- **Phase 2 (The Leap)**: Simulating the passage of time until cryptographically relevant quantum computers are available.
- **Phase 3 (Decrypt Later)**: Using **Shor's Algorithm** (via Qiskit) to factor the RSA modulus and recover the secret PIN.

### 4. Benchmarking & Reporting
- Standalone CLI tool (`benchmark_cli.py`) for offline performance analysis.
- Detailed JSON/CSV reports generated in the `docs/` directory.

## 🛠 Tech Stack
- **Backend**: Python 3.9+, Flask, SQLAlchemy (SQLite).
- **Cryptography**: `cryptography` (Classical), `liboqs-python` (PQC), `qiskit` (Quantum Simulation).
- **Frontend**: HTML5, CSS3, Vanilla JS, Chart.js.
- **Testing**: Pytest with integration and unit coverage.

## 📊 Deliverables
- Fully functional PoC application.
- Comprehensive test suite.
- Detailed benchmarking results.
- Academic and industry-focused documentation.
